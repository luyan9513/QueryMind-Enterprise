## 8. 变更与失效条件

出现下列变化必须重新评测：

- 表、字段、主外键或数据类型变化。
- 指标定义、过滤口径或 JOIN 规则变化。
- Agent/Judge 模型、Prompt、Schema Retrieval 或 Governance 变化。
- 数据快照发生明显分布漂移。
- 评测规则或结果规范变化。
